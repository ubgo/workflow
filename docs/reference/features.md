# Feature index

Every feature of the library on one page, grouped by area, with the package that provides it, the guide section that explains it and the runnable example that shows it. Use it to answer "does it do X, and where is that written down?" without reading the guides in order.

The list is built from the code: the exported types, functions and options of every package in every module (`workflow`, `clock`, `cron`, `memory`, `middleware`, `batch`, `failover`, `workflowtest`, `events`, `dsl`, `hybrid`, `regional`, `schedexport`, `cutover`, `httprun`, `push`, and the separate modules `admin`, `cli`, `hatchet`, `otel`, `recorder` with `recorder/recordertest`, `recorder/sqlrecorder`, `redis`, `sentry`, `sqlstore` with `sqlstore/outbox`, `sqlstore/pgnotify` and `sqlstore/pgxtx`), every command of the `workflow` command line, every route of the admin JSON API and the Taskfile tasks you run from the repository root. It has 556 rows.

An **Example** link goes to a program under `examples/` (or a Go example test) whose code uses the feature's API and is run by `go test`; a dash means no example shows the feature yet, and the guide section is the place to start. A dash under **Guide** means no guide section explains the feature yet; its doc comment in the package is the reference until one does. A **Package** is a path inside `github.com/ubgo/workflow`, where `workflow` is the root package, unless it names another module.
